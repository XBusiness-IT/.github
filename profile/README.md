# X Business IT

Цифровая платформа [**X Business Club**](https://xbusinessclub.ru/).

Мы строим экосистему для мероприятий, нетворкинга и сообщества: от регистрации и чек-ина до мобильных приложений и Telegram Mini App.

---

### Что внутри

| Направление | Зачем |
|---|---|
| **Мероприятия** | Афиша, регистрация, билеты и QR-пропуск |
| **Нетворкинг** | Контакты, Random Coffee, знакомства на событиях |
| **Клуб** | Профиль участника, вакансии, операторские инструменты |
| **Чек-ин** | Desktop-приложение для входа гостей на мероприятия |
| **Мобильные приложения** | iOS и Android оболочки сайта клуба |

### Стек

- **Backend** — микросервисы (Gateway, Profiles, Events, Contacts, Random Coffee и др.)
- **Frontend** — React / TypeScript, Telegram Mini App
- **Bots** — Telegram-боты для событий и сервисных уведомлений
- **Mobile** — SwiftUI (iOS), Kotlin (Android)
- **Desktop** — Electron-приложение чек-ина
- **Infra** — Docker Compose, Traefik, CI/CD на QA и Prod
